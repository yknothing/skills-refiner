# 决策卡（分诊）

用户需要决定下一步时，按相关缺口类出示卡片。若已授权只读评估，直接传递证据与范围并继续，不重复确认。全景**只路由**，不输出突变命令；实际变更仍需对应工具的精确计划与确认。

| 缺口类 | 风险 | 半句原因 | 交给谁 |
|---|---|---|---|
| 链接损坏 | 高 | 投影不可用，Agent 可能加载失败 | skill-hygiene（只读评估） |
| 命名冲突 | 高 | 同名异内容可能导致错载 | skill-hygiene（默认保留） |
| 清单与现实不符 | 中 | 意图与磁盘不一致 | skill-hygiene collection / 人工确认意图 |
| 部分 Agent 已出现 | 低 | 所选且存在的 Agent 中仅部分有投影 | 调整覆盖或 hygiene 评估是否补投影 |
| 仅在 Agent | 中 | 可能是孤儿链接或外来副本 | skill-hygiene |
| 仅在源目录 | 低 | 未分发到所选 Agent | 调整覆盖或 hygiene 评估 |
| 暂无法判定 | 低 | 收集器字段不足，不猜测 | 上游补字段或 skill-debug |
| 齐全 | 无 | 拓扑一致 | 仅阅览 |

每张卡的选择：`继续评估` / `稍后再说` / `忽略此类`。  
默认仅会话有效；用户明确要求「记住」才持久化本机偏好。
