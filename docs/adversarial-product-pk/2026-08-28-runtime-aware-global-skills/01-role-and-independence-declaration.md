# 01 — Role and Independence Declaration

## Review topology

| Role | Mandate | First-pass visibility | Independence level |
|---|---|---|---|
| Champion | Defend the smallest useful governance baseline | implementation packet and live facts | L2 agent-separated |
| Challenger | Attack authority, recovery, identity, qualification and promotion claims | target state was visible; Champion answer was not | L2 role-blind, not outcome-blind |
| Primary synthesizer | Resolve objections against code and fresh local evidence | both first passes and live machine | not independent |
| Successor transaction reviewer | Attack ProdCraft upgrade/recovery and cross-repository preservation | current plans, historical controller evidence, live status | L2 read-only |
| Live-upgrade reviewer | Attack Better drift→repair→successor interleaving and collision normalization | live generation, repair ledger, quarantines and negative tests | L2 read-only |

No reviewer was an external team, separately operated model provider, or fresh-context human auditor. “Independent review” is
therefore forbidden wording. The accepted label is **L2 Agent-separated**.

## Contamination declaration

The Challenger received the decision target and evidence packet, so it could infer intended outcomes. It did not receive the
Champion response before its first pass. The final pass saw current active artifacts and implementation baseline. This is enough
for adversarial separation, not for blinded certification.

## Evidence exclusions

- User-owned unrelated untracked documents were not opened, edited, staged or used as evidence.
- Raw runtime prompts/transcripts and private host paths were not copied into this package.
- Packet-reported historical test results are labelled as such when a reviewer did not rerun them.
- Same-user self-hashed evidence is consistency evidence, not tamper-proof platform attestation.
