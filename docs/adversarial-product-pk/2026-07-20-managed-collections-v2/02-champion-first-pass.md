# Champion First Pass

## Initial case

The declarative controller was stronger than copying ProdCraft V1 because it separated repository content, reviewed selection, installer history, deployment intent, observed filesystem, and runtime claims. Its crash recovery, generation replacement, external catalog and schema adapters were credible.

## Initial veto

The advocate nevertheless returned `NOT_READY`:

1. `bs-visual-design` was accepted by a permissive line parser but rejected by strict YAML because of unquoted `Deep-tier: `.
2. Better packaged `docs/patterns` without its declared `docs/research`, `tools/check-patterns.sh`, and `skills.json` dependencies.
3. Current runtime discovery was not yet a fresh-host fact.

The advocate prohibited patching installed bytes while continuing to claim the unchanged GitHub commit as source truth.

## Final advocate position

The corrected design uses portable-YAML qualification, an explicit 8-member selection, compatible historical profiles, four shared inputs, resource-origin closure, plan.v3 collision snapshots and a bounded Finder metadata policy. This preserves source truth and rollback while allowing repository-qualified same-name coexistence.
